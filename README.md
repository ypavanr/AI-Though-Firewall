# 🧬 The 4-Agent Analysis Pipeline

## 1️⃣ AI Detection Agent

### Purpose
Determines whether content was written by a human or generated by AI.

### Model
```python
roberta-base-openai-detector
```

### Stack
- HuggingFace Transformers
- RoBERTa Sequence Classification

### Output
```json
{
  "ai_probability": 0.94,
  "classification": "AI Generated"
}
```

---

## 2️⃣ Emotional Manipulation Agent

### Purpose
Detects psychological coercion techniques.

### Detects
- Fear
- Rage
- Disgust
- Anxiety
- Panic
- Outrage

### Model
```python
llama-3.3-70b-versatile
```

### Provider
Groq API

### Calculation
```python
Top_1_Emotion_Score + (Top_2_Emotion_Score * 0.5)
```

### Output
```json
{
  "manipulation_score": 82,
  "top_emotion_1": "Fear",
  "top_emotion_2": "Anger"
}
```

---

## 3️⃣ Misinformation Fact-Checking Agent

### Purpose
Debunks false claims and propaganda.

### Pipeline
1. Groq extracts factual claims
2. Google Fact Check API verifies them

### Sources
- Snopes
- PolitiFact
- IFCN databases
- Global fact-check organizations

### Output
```json
{
  "claim": "The Earth is flat",
  "rating": "False"
}
```

# 📊 Risk Scoring Engine

All agent outputs are unified into a single **Cognitive Threat Score**.

## Formula

```python
total_risk = (
    manipulation_score * 0.3
) + (
    phishing_prob * 0.4
) + (
    spam_prob * 0.2
) + (
    len(misinfo_claims) * 10
)

final_score = min(total_risk, 100.0)
```
